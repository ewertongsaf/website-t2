# Website da T2

Site oficial da **Subturma T2** da Turma 30 do ITA (Instituto Tecnológico de Aeronáutica), desenvolvido pela equipe de computação da [ITA Júnior](https://itajunior.com.br).

**[website-t2.vercel.app](https://website-t2.vercel.app)**

---

## Páginas

| Página | Descrição |
|---|---|
| **Início** | Apresentação da turma com stats gerais |
| **Sobre** | Fotos e registros da T2 — e a famosa argumentação escolástica do Nada Genérico |
| **Agenda/Cronograma** | Calendário e tabela de horários do semestre |
| **Membros** | Todos os 45 alunos da T2 com apelidos e fotos |
| **Calculadora de faltas** | Calcula o percentual de faltas por disciplina com limite fixo de 15% |

---

## 🛠️ Tecnologias

- HTML5, CSS3, JavaScript (vanilla)
- Font Awesome (ícones)
- Deploy via [Vercel](https://vercel.com)

## Como rodar localmente

Sem dependências ou build step — é HTML estático puro.

```bash
git clone https://github.com/ewertongsaf/website-t2.git
cd website-t2
```

Abra o `index.html` no navegador, ou use a extensão **Live Server** no VS Code para hot reload.
